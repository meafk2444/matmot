# Matmot

Un petit site rigolo dédié à Matmot (animateur/illustrateur 2D) : le
personnage danse en boucle, et un clic déclenche une action aléatoire
différente à chaque fois (confettis, rotation, flip, moonwalk, pluie
d'emojis, flash d'écran, bulle de texte...).

## Fichier

Un seul fichier : `index.html`. L'image est encodée directement dedans
(en base64), donc **aucun dossier `assets/` n'est nécessaire** — pas de
souci de chemin cassé, ça marche partout, y compris en ouvrant le
fichier directement en local.
